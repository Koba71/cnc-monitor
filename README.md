# Мониторинг станка ЧПУ

Программа читает с экрана управляющей программы электроэрозионного станка (по умолчанию `AutoCut.exe`) координаты, время обработки, скорость и номер детали, затем записывает снимки состояния в CSV.

Дополнительно можно открыть **веб-обзор цеха**: плитки станков с превью окна AutoCut и текущими цифрами. Идея панели взята у открытой программы [Veyon](https://github.com/veyon/veyon) (GPL-2.0), код Veyon сюда не копировался.

## Что нужно

- Windows 7 / 8 / 10 / 11 — для чтения окна станка
- Python 3.8 или новее
- Запущенная управляющая программа станка (`AutoCut.exe`)
- Офисный обзор (`--dashboard-only`) работает и на Linux / другом ПК в сети

## Установка Python

Если Python ещё не установлен:

1. Скачайте установщик с [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Запустите его и **обязательно отметьте** пункт **Add python.exe to PATH**
3. Нажмите Install Now
4. Проверьте в командной строке:

```bat
python --version
```

Должно появиться что-то вроде `Python 3.12.x`.

## Установка зависимостей

Откройте командную строку в папке с программой и выполните:

```bat
pip install -r requirements.txt
```

Или вручную:

```bat
pip install pywin32 psutil
```

Если `pip` не находится, используйте:

```bat
python -m pip install pywin32 psutil
```

## Запуск

1. Запустите управляющую программу станка (`AutoCut.exe`).
2. В папке со скриптом выполните:

```bat
python monitor.py
```

В консоли появится статус: найдено ли окно и какие значения считаны.

Файл журнала создаётся рядом со скриптом:

```
machine_log.csv
```

Колонки (разделитель — точка с запятой):

```
Timestamp;X;Y;WorkingTime;SurplusTime;Speed;DetailNo
```

Каждая строка — снимок состояния станка в момент опроса.

## Обзор цеха (плитки как в Veyon)

На ПК станка:

```bat
python monitor.py --dashboard --name "Эрозия 1"
```

Откроется браузер: `http://127.0.0.1:8080/` — плитка с экраном AutoCut, координатами, временем и скоростью.

Чтобы смотреть со соседнего компьютера в цехе:

```bat
python monitor.py --dashboard --bind 0.0.0.0 --port 8080 --name "Эрозия 1" --id edm-1
```

На офисном ПК скопируйте `machines.example.json` в `machines.json`, пропишите адреса станков и запустите только панель:

```bat
python monitor.py --dashboard-only --machines machines.json --bind 0.0.0.0
```

| Флаг              | Смысл                                      |
|-------------------|--------------------------------------------|
| `--dashboard`     | Веб-панель + опрос AutoCut                 |
| `--dashboard-only`| Только панель (офис, без окна станка)      |
| `--bind 0.0.0.0`  | Доступ из локальной сети                   |
| `--port 8080`     | Порт панели                                |
| `--name`          | Подпись на плитке                          |
| `--id`            | Идентификатор в списке станков             |
| `--machines`      | JSON со списком удалённых станков          |
| `--no-browser`    | Не открывать браузер                       |
| `--no-csv`        | Не писать `machine_log.csv`                |

Панель показывает экраны ваших станков в локальной сети. Не выставляйте `--bind 0.0.0.0` в интернет без защиты сети.

## Veyon — открытая программа

[Veyon](https://github.com/veyon/veyon) (Virtual Eye On Networks) — свободное ПО для обзора и управления группой компьютеров. Лицензия **GPL-2.0**, исходники на GitHub, актуальные сборки: [релизы](https://github.com/veyon/veyon/releases) (сейчас 4.11.x). Сайт: [veyon.io](https://veyon.io/), документация: [docs.veyon.io](https://docs.veyon.io/).

Что умеет Veyon и чем это полезно в цехе:

| Возможность Veyon     | Для предприятия                         |
|-----------------------|-----------------------------------------|
| Обзор экранов         | Видеть ПК всех станков с одного места   |
| Удалённый доступ      | Помочь оператору, не подходя к станку   |
| Снимки экрана         | Зафиксировать состояние окна программы  |
| Сообщения / блокировка| Сервисные объявления на ПК цеха         |
| Питание               | Wake-on-LAN, перезагрузка ПК станка     |
| WebAPI                | Снять кадр экрана по HTTP               |

Этот репозиторий **не заменяет Veyon**. Он читает цифры из AutoCut в CSV и даёт лёгкую панель телеметрии. Вместе они закрывают разные задачи:

1. На ПК станка — `python monitor.py --dashboard` (журнал обработки).
2. По желанию — [Veyon Service](https://docs.veyon.io/en/latest/admin/installation.html) на тех же ПК и **Veyon Master** в кабинете, если нужен полноценный удалённый рабочий стол и управление.

Код Veyon на C++/Qt, собирать его в этот проект не нужно: ставьте официальный установщик с [veyon.io/download](https://veyon.io/download/).

## Остановка

Нажмите **Ctrl+C** в окне консоли. Программа корректно завершится и сохранит уже записанные строки.

## Настройка

В начале файла `monitor.py` можно изменить:

| Переменная            | Смысл                                      | По умолчанию        |
|-----------------------|--------------------------------------------|---------------------|
| `PROCESS_NAME`        | Имя процесса управляющей программы         | `AutoCut.exe`       |
| `MACHINE_NAME`        | Подпись станка на плитке                   | `Станок ЧПУ`        |
| `POLL_INTERVAL_SEC`   | Интервал опроса, секунды                   | `3`                 |
| `CSV_FILENAME`        | Имя файла журнала                          | `machine_log.csv`   |
| `DEBUG`               | Печатать все найденные тексты Static       | `False`             |

Если имя процесса другое, посмотрите его в диспетчере задач (вкладка «Подробности») и подставьте в `PROCESS_NAME`.

## Если данные не считываются

1. Убедитесь, что `AutoCut.exe` запущен и его окно видно (не обязательно поверх остальных).
2. Проверьте `PROCESS_NAME` — оно должно совпадать с именем в диспетчере задач.
3. Поставьте в `monitor.py` `DEBUG = True` и запустите снова: в консоль выведутся все тексты элементов `Static`. По ним можно понять, в каком виде программа отдаёт координаты и время.
4. Запустите командную строку **от имени администратора**, если управляющая программа станка тоже запущена с правами администратора.

Программа не завершается при ошибках: если окно исчезло или текст не прочитался, она пишет сообщение в консоль и пробует снова через заданный интервал.
