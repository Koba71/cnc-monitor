# Где что ставить и как настраивать

Инструкция для цеха: какие программы на какой компьютер, в каком порядке и какие цифры прописать.

Две разные вещи, их можно использовать вместе или по отдельности:

| Программа | Зачем | Куда ставить |
|-----------|--------|--------------|
| **Этот монитор** (`monitor.py`) | Читает цифры из окна AutoCut, пишет CSV, показывает плитки станков в браузере | ПК станка обязательно; офисный ПК — если нужен общий обзор |
| **Veyon** (по желанию) | Живой экран всего рабочего стола, удалённое управление мышкой/клавиатурой | На ПК станка — служба; в кабинете — Veyon Master |

Veyon **не заменяет** монитор AutoCut: он не понимает координаты и время обработки. Монитор **не заменяет** Veyon: он не даёт полноценный удалённый рабочий стол.

---

## 1. Карта компьютеров

Пример на два станка. Подставьте свои имена и адреса.

```
Кабинет / офис                         Цех
┌─────────────────────────┐            ┌─────────────────────────┐
│ Офисный ПК              │            │ ПК станка «Эрозия 1»    │
│                         │            │ AutoCut.exe             │
│ Браузер → обзор цеха    │  сеть      │ python monitor.py       │
│ python --dashboard-only │◄──────────►│   --dashboard :8080     │
│ machines.json           │            │ IP, например 192.168.0.11
│ Veyon Master (по жел.)  │            │ Veyon Service (по жел.) │
└─────────────────────────┘            └─────────────────────────┘
                                       ┌─────────────────────────┐
                                       │ ПК станка «Эрозия 2»    │
                                       │ то же самое             │
                                       │ IP, например 192.168.0.12
                                       └─────────────────────────┘
```

Что **не** ставить:

- На ПК станка **не нужен** офисный `machines.json` (он нужен там, откуда смотрят все станки).
- На офисном ПК **не нужен** AutoCut и **не нужно** читать окно станка.
- Veyon Master на ПК станка обычно **не ставят** (там только служба).

## 2. Что подготовить заранее

1. Флешка или общая папка с этой программой (файлы `monitor.py`, `parse.py`, `dashboard.py`, папка `web`, `requirements.txt`, `start-stanok.bat`, `start-office.bat`).
2. Список ПК цеха: имя станка, имя компьютера, IP-адрес.
3. Все ПК в **одной локальной сети** (один роутер / один коммутатор). В интернет ничего открывать не нужно.

Рекомендуется раздать ПК станков **постоянные** IP (в роутере «резервация DHCP» или вручную), иначе после перезагрузки адрес сменится и офисная панель перестанет их находить.

| Станок        | Пример имени ПК | Пример IP       | Порт монитора |
|---------------|-----------------|-----------------|---------------|
| Эрозия 1      | STANOK-1        | 192.168.0.11    | 8080          |
| Эрозия 2      | STANOK-2        | 192.168.0.12    | 8080          |
| Офис          | OFIS            | 192.168.0.5     | 8080          |

## 3. ПК станка (Windows у AutoCut)

Делайте **на каждом** компьютере, который управляет станком.

### 3.1. Система

- Windows 7 / 8 / 10 / 11.
- Должна быть запущена управляющая программа станка (`AutoCut.exe` или другое имя — см. п. 3.5).
- Если AutoCut запущен **от имени администратора**, монитор тоже запускайте от администратора.

### 3.2. Установить Python

**Windows 10 / 11:** свежий Python 3 с [python.org/downloads](https://www.python.org/downloads/).

**Windows 7:** только **Python 3.8.10** (новые версии Windows 7 не поддерживают):  
[https://www.python.org/downloads/release/python-3810/](https://www.python.org/downloads/release/python-3810/)  
файл `Windows x86-64 executable installer` (64-бит) или `Windows x86 executable installer` (32-бит).

В установщике:

1. **Обязательно** поставьте галочку **Add python.exe to PATH**.
2. Нажмите **Install Now**.
3. Откройте командную строку (`Win+R` → `cmd`) и проверьте:

```bat
python --version
```

Должно быть `Python 3.8.x` или новее. Если «не является внутренней командой» — Python не в PATH: переустановите с галочкой или перезагрузите ПК.

### 3.3. Скопировать программу

Скопируйте всю папку проекта, например в:

```
C:\cnc-monitor\
```

Внутри должны быть как минимум:

```
C:\cnc-monitor\monitor.py
C:\cnc-monitor\parse.py
C:\cnc-monitor\dashboard.py
C:\cnc-monitor\requirements.txt
C:\cnc-monitor\start-stanok.bat
C:\cnc-monitor\web\index.html
C:\cnc-monitor\web\app.js
C:\cnc-monitor\web\style.css
```

### 3.4. Установить библиотеки

Откройте командную строку **в этой папке**:

```bat
cd /d C:\cnc-monitor
python -m pip install -r requirements.txt
```

Нужны пакеты `pywin32` и `psutil`. Если `pip` не находится:

```bat
python -m pip install pywin32 psutil
```

### 3.5. Проверить имя процесса AutoCut

1. Запустите программу станка.
2. Диспетчер задач → вкладка **Подробности**.
3. Найдите процесс окна станка. Часто это `AutoCut.exe`.
4. Если имя другое — откройте `monitor.py` блокнотом и в начале файла замените:

```python
PROCESS_NAME = "AutoCut.exe"
```

на фактическое имя (как в диспетчере задач).

### 3.6. Прописать имя станка в ярлыке запуска

Откройте блокнотом `start-stanok.bat` и поправьте три места:

```bat
set MACHINE_ID=edm-1
set MACHINE_NAME=Эрозия 1
set PORT=8080
```

- `MACHINE_ID` — короткое имя латиницей без пробелов (`edm-1`, `edm-2`). Его же потом пишут в офисном `machines.json`.
- `MACHINE_NAME` — подпись на плитке, можно по-русски.
- На втором станке: `edm-2` и `Эрозия 2`. Порт лучше везде оставить `8080`.

### 3.7. Узнать IP этого ПК

В командной строке:

```bat
ipconfig
```

Ищите **IPv4-адрес** адаптера, через который ПК в цеховой сети, например `192.168.0.11`. Запишите: этот адрес понадобится на офисном ПК.

Чтобы адрес не прыгал: в роутере закрепите IP за MAC-адресом ПК либо назначьте статический IP в свойствах Ethernet.

### 3.8. Открыть порт в брандмауэре Windows

Иначе соседние компьютеры не увидят панель.

Запустите командную строку **от имени администратора** и выполните:

```bat
netsh advfirewall firewall add rule name="CNC Monitor 8080" dir=in action=allow protocol=TCP localport=8080
```

Если пользуетесь сторонним антивирусом с своим файрволом — разрешите входящие TCP 8080 там тоже.

### 3.9. Первый запуск на станке

1. Запустите AutoCut.
2. Дважды щёлкните `start-stanok.bat`  
   или в папке программы:

```bat
python monitor.py --dashboard --bind 0.0.0.0 --port 8080 --name "Эрозия 1" --id edm-1
```

`--bind 0.0.0.0` нужен, чтобы панель была видна **с других ПК**. Без него она откроется только на этом компьютере.

В консоли должно появиться примерно:

```
Мониторинг ЧПУ запущен
Веб-обзор: http://127.0.0.1:8080/
Окно найдено: ...
X=...  Y=...  WorkingTime=...
```

На этом же ПК откройте браузер: [http://127.0.0.1:8080/](http://127.0.0.1:8080/) — плитка станка.

Рядом со скриптом появится журнал:

```
C:\cnc-monitor\machine_log.csv
```

Его можно открыть в Excel (разделитель — точка с запятой).

Остановка: в окне консоли **Ctrl+C**. Окно консоли не закрывайте, пока нужен мониторинг.

### 3.10. Автозапуск после включения ПК

Монитор должен работать **в сеансе оператора** (когда на экране AutoCut). Не ставьте его как службу «без входа в Windows» — окно станка тогда не прочитается.

1. Нажмите `Win+R`, введите `shell:startup`, Enter.
2. Создайте ярлык на `C:\cnc-monitor\start-stanok.bat`.
3. В свойствах ярлыка можно поставить «Свёрнутое окно».

Либо планировщик заданий: триггер «при входе пользователя», действие — тот же `start-stanok.bat`, галочка «выполнять только для вошедшего пользователя».

## 4. Офисный ПК (обзор всех станков)

Это компьютер, с которого мастер смотрит цех. Windows или Linux.

### 4.1. Что установить

- Python 3.8+ (на Windows — тоже с галочкой PATH).
- Ту же папку программы, например `C:\cnc-monitor\`.
- Библиотеки `pywin32` на офисном ПК **не обязательны**, если запускаете только панель:

```bat
cd /d C:\cnc-monitor
python -m pip install -r requirements.txt
```

На Linux достаточно системного Python 3, пакеты Windows не ставятся.

### 4.2. Файл списка станков

1. Скопируйте `machines.example.json` → `machines.json` **в ту же папку**, где `monitor.py`.
2. Откройте `machines.json` блокнотом (кодировка UTF-8).
3. Пропишите **те самые** id и IP, что на станках:

```json
{
  "title": "Цех ЧПУ",
  "machines": [
    {
      "id": "edm-1",
      "name": "Электроэрозия 1",
      "url": "http://192.168.0.11:8080"
    },
    {
      "id": "edm-2",
      "name": "Электроэрозия 2",
      "url": "http://192.168.0.12:8080"
    }
  ]
}
```

Правила:

- `id` совпадает с `--id` на ПК станка (`edm-1`).
- `url` — `http://IP-станка:8080` без слэша в конце.
- Порт в URL = порт из `start-stanok.bat`.
- Запятые как в примере: после каждого станка кроме последнего.

### 4.3. Запуск обзора

Дважды щёлкните `start-office.bat` или:

```bat
python monitor.py --dashboard-only --machines machines.json --port 8080
```

Браузер: [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

Должны появиться плитки всех станков. Зелёный статус — монитор на станке запущен и окно AutoCut найдено. Красный «офлайн» — нет связи (ПК выключен, другой IP, закрыт порт, монитор не запущен).

Если смотреть панель будут и с других компьютеров кабинета:

```bat
python monitor.py --dashboard-only --machines machines.json --bind 0.0.0.0 --port 8080
```

и откройте в брандмауэре офисного ПК тот же порт 8080.

## 5. Проверка связи по шагам

На **ПК станка** (после запуска монитора):

```bat
ipconfig
```

С **офисного ПК** в командной строке (подставьте IP станка):

```bat
ping 192.168.0.11
```

Должны идти ответы. Если «превышен интервал» — разные сети, Wi‑Fi гость, или пинг режет брандмауэр.

Затем в браузере офисного ПК откройте напрямую:

```
http://192.168.0.11:8080/
```

Если плитка открылась — сеть и порт в порядке, можно пользоваться общей панелью. Если не открывается — вернитесь к п. 3.8 (брандмауэр) и проверьте, что монитор запущен с `--bind 0.0.0.0`.

## 6. Настройки в `monitor.py` (на ПК станка)

Менять нужно редко. Файл открывать блокнотом, в начале:

| Переменная            | Когда менять                                      | Обычное значение  |
|-----------------------|---------------------------------------------------|-------------------|
| `PROCESS_NAME`        | Другое имя exe управляющей программы              | `AutoCut.exe`     |
| `MACHINE_NAME`        | Подпись по умолчанию, если не указали `--name`    | `Станок ЧПУ`      |
| `POLL_INTERVAL_SEC`   | Как часто читать окно (секунды)                   | `3`               |
| `CSV_FILENAME`        | Имя журнала                                       | `machine_log.csv` |
| `DEBUG`               | `True`, если цифры не находятся                   | `False`           |

Флаги командной строки (их уже прописывают bat-файлы):

| Флаг                 | Кто использует | Смысл |
|----------------------|----------------|--------|
| `--dashboard`        | ПК станка      | Читать AutoCut и открыть веб-плитку |
| `--dashboard-only`   | Офис           | Только собрать плитки по сети |
| `--bind 0.0.0.0`     | ПК станка      | Пускать коллег из цеха/офиса |
| `--port 8080`        | Оба            | Порт в браузере |
| `--name "..."`       | ПК станка      | Подпись на плитке |
| `--id edm-1`         | ПК станка      | Код станка в `machines.json` |
| `--machines файл.json` | Офис         | Список станков |
| `--no-browser`       | Оба            | Не открывать браузер самому |
| `--no-csv`           | ПК станка      | Не писать журнал |

## 7. По желанию: Veyon (живые экраны и управление)

Ставьте, если нужно **видеть весь рабочий стол** оператора и управлять им, а не только цифры AutoCut.

Официально: Windows **10 / 11** (свежий Veyon 4.11 на Windows 7 уже не рассчитан). Скачать: [veyon.io/download](https://veyon.io/download/) — для обычных ПК берите **Windows 64 bit**. Документация: [docs.veyon.io](https://docs.veyon.io/en/latest/admin/installation.html).

### 7.1. ПК станка — только служба

1. Запустите установщик **от администратора**.
2. В выборе компонентов **снимите** галочку **Veyon Master** (мастер в цехе не нужен).
3. Дойдите до конца. Откроется **Veyon Configurator**.
4. Пока закройте его: ключи удобнее создать один раз на офисном ПК и потом перенести.

После настройки (п. 7.3) на станке должна работать служба Veyon (в `services.msc` — Veyon Service). В брандмауэре входящий TCP **11100** (порт Veyon по умолчанию):

```bat
netsh advfirewall firewall add rule name="Veyon 11100" dir=in action=allow protocol=TCP localport=11100
```

### 7.2. Офисный ПК — Master + Configurator

1. Тот же установщик, **оставьте Veyon Master**.
2. Откройте **Veyon Configurator** от администратора.

### 7.3. Ключи доступа (для цеха без домена)

Без пароля домена удобнее **аутентификация по файлу ключа**.

На **офисном ПК** в Configurator:

1. Слева **Authentication keys** (Ключи аутентификации).
2. **Create key pair** (Создать пару ключей).
3. Имя короткое, например `ceh` или `teacher`.
4. Для **закрытого** ключа укажите группу, в которую входит только мастер (кто имеет право смотреть станки).
5. Для **открытого** ключа — группа, которую могут читать все (часто Users / Все).
6. Слева **General → Authentication**: метод **Key file authentication**.
7. Меню **File → Save settings to file** — сохраните `veyon-config.json` на флешку.
8. Экспортируйте **открытый** ключ (public) на флешку. **Закрытый** ключ с флешки на станки **не копируйте**.

На **каждом ПК станка**:

1. Установите Veyon без Master (п. 7.1).
2. Configurator → **File → Load settings from file** → ваш `veyon-config.json` → кнопка **Apply**.
3. Либо в командной строке администратора:

```bat
"C:\Program Files\Veyon\veyon-cli.exe" config import C:\veyon-config.json
"C:\Program Files\Veyon\veyon-cli.exe" authkeys import ceh/public C:\ceh_public_key.pem
```

Подставьте своё имя ключа вместо `ceh`.

### 7.4. Список компьютеров в Master

На офисном ПК, Configurator → **Locations & computers**:

1. Добавьте площадку, например `Цех`.
2. Добавьте компьютеры: имя (Эрозия 1) и **IP или имя ПК** (`192.168.0.11`).
3. **Apply**.
4. Запустите **Veyon Master** — должны появиться плитки рабочих столов.

Если плитка пустая: служба на станке запущена, порт 11100 открыт, открытый ключ импортирован, IP верный.

Подробности по всем пунктам Configurator: [документация Veyon](https://docs.veyon.io/en/latest/admin/configuration.html).

## 8. Частые проблемы

| Что видите | Что проверить |
|------------|----------------|
| `python` не является командой | Нет Python или забыли галочку PATH, перезагрузите ПК |
| Окно процесса не найдено | AutoCut запущен? Имя в `PROCESS_NAME` как в диспетчере задач? Монитор запущен от администратора, если AutoCut тоже |
| Данные не распознаны | В `monitor.py` поставьте `DEBUG = True`, перезапустите, пришлите тексты Static из консоли |
| С офиса страница не открывается | На станке `--bind 0.0.0.0`, брандмауэр 8080, `ping` до IP, монитор не закрыт |
| Плитка «офлайн» | Неверный IP в `machines.json`, другой порт, ПК станка выключен |
| Excel «ломает» CSV | Файл в UTF-8 с BOM; разделитель `;`; открывать через «Данные → из текста» |
| Veyon не подключается | Win 10/11, служба запущена, порт 11100, открытый ключ на станке, закрытый только в кабинете |

---

## 9. Безопасность

- `--bind 0.0.0.0` и порт 8080 открывают **снимок экрана станка внутри вашей сети**. Не пробрасывайте этот порт на роутере в интернет.
- Журнал `machine_log.csv` лежит на диске ПК станка — по сети сам не уходит.
- Закрытый ключ Veyon храните только на офисном ПК (и в сейфе/архиве), не на станках и не в общей папке «на всех».
